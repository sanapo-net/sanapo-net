## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. Наследуется от базового класса [[AppGraphsIcmp.class]] для повторного использования логики таблиц и фильтров. 
Для отрисовки архивных графиков использует специализированные объекты [[graphs_render_agr.class]]. 
Является встраиваемым виджетом рабочего поля суб-окна ([[MdiWindow.class]]) основного интерфейса. 
Содержит свойство-словарь с кнопками управления (объектами [[MdiButton.class]]). 

Данные запрашивает через интерфейс главного менеджера баз данных [[db_icmp.unit]]. Для ускорения работы приложение полагается на заложенную в менеджере оптимизацию: при больших периодах оно считывает готовые агрегаты из легких файлов [[icmp_hours.database]] или [[icmp_days.database]], не нагружая систему сырыми логами.
