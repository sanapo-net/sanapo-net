## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. Для отрисовки графиков использует объекты [[graphs_render.class]]. 
Является встраиваемым виджетом рабочего поля суб-окна ([[MdiWindow.class]]) основного интерфейса фреймворка. 
Содержит свойство-словарь с кнопками управления (объектами [[MdiButton.class]]). 
Для экономии ресурсов процессора и видеокарты приложении не запрашивает сырые данные напрямую из тяжелых файлов истории, а считывает оперативную информацию из буфера [[buffer_icmp.unit]] или легкой БД [[icmp_10m.database]] через интерфейс [[db_icmp.unit]].
