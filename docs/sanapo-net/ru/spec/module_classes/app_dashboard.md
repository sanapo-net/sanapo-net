## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. На данный момент юнит находится на стадии проектирования интерфейсных концепций и требует детальной проработки внутренней логики перед запуском в полноценную разработку. Полномасштабная реализация компонента запланирована сразу после релиза базовой версии фреймворка sanapo-net v1.0.

Приложение выступает главным визуальным приемником оперативных алертов и аналитики, работая в тесной связке со следующими компонентами системы:
* Подписывается на шину событий [[sanapo.fw]] для мгновенного получения сообщений от юнита [[analysator.unit.md]] о смене статусов хостов (Online / Offline) и критических отклонениях медианы за 1, 3 и 10 минут.
* Выводит агрегированные индикаторы и графики-информеры на основе данных из оперативной in-memory матрицы [[buffer_icmp.unit]] и легкой БД [[icmp_10m.database]] через интерфейс [[db_icmp.unit]], полностью исключая тяжелые прямые запросы к историческим базам данных при рендеринге дашборда.
* Будет являться одним из ключевых суб-приложений, встраиваемых в рабочее поле окон [[MdiWindow.class]] главного интерфейса [[ui.unit]].
