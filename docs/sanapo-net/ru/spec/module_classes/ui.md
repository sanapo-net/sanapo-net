## Главное окно
Главное окно состоит из:
- Боковой панели кнопок
- Поля для окон

В строке заголовка главного окна отображается:
- иконка приложения
- заголовок приложения: `f"sanapo-net: {system_name}"`, где `system_name` - это имя системы, заданное пользователем (параметр фреймворка sanapo)
- стандартные три кнопки управления окном

Интерфейс является многодокументным интерфейсом (MDI: Multiple Document Interface).
В рамках поля для окон свободно перемещаются и меняют размер окна суб-приложений за счёт манипуляций от пользователя.

## Окна
Окна являются объектами [класса `sub_window`](../utility_classes/ui.md#subwindow)
Поведение окон (управление геометрией и Snap-функции):
-   **Максимизация перетаскиванием**: при зажатии ЛКМ на полосе заголовка и перемещении курсора к верхней границе экрана (рабочей области), окно автоматически максимизируется — принимает размер, равный полному размеру поля для окон.
-   **Боковой Snap (разделение экрана)**: при зажатии ЛКМ на полосе заголовка и перемещении курсора к левой или правой границе экрана, окно принимает размер, равный ровно половине ширины поля для окон, и позиционируется у соответствующего края (слева или справа).
-   **Восстановление размера при перетаскивании**: если окно находится в режиме максимизации или бокового Snap, то при зажатии ЛКМ на заголовке и последующем движении мыши окно мгновенно восстанавливает свои исходные пользовательские размеры, которые оно имело до автоматического изменения геометрии. При этом геометрический центр полосы заголовка (или относительная координата клика) автоматически привязывается к текущей позиции курсора для непрерывного перемещения.
-   **Кнопка Развернуть «🗖»**: при одиночном клике на кнопку «🗖» окно разворачивается на всю рабочую область (максимизируется). Символ на кнопке управления окном мгновенно заменяется на пиктограмму восстановления «🗗».
-   **Кнопка Восстановить «🗗»**: при одиночном клике на кнопку «🗗» окно возвращается к исходным пользовательским размерам и позиции, которые были до максимизации. Символ на кнопке управления окном мгновенно заменяется на пиктограмму развёртывания «🗖».

## Боковая панель кнопок
Боковая панель кнопок располагается вертикально слева, ширина 48 пикселей. Наполняется кнопками сверху вниз. 
При переполнении кнопками добавляется визуальная полоса прокрутки шириной 2-5 пикселей, в таком виде панель прокручивается колёсиком мыши.

Содержит в себе базовые кнопки боковой панели, которые являются объектами класса [MainBtBase](../utility_classes/main_bt_base.md). Занимает пространство 48×48 пикселей.
Базовая кнопка может являться:
- обычной кнопкой запуска действия (класс `MainBtBase`)
- кнопкой-переключателем (класс `MainBtSwitch`)
- кнопкой-меню (класс `MainBtMenu`)
- кнопкой запуска суб-приложения с его окном (класс `MainBtApp`)

## Темы
Должно поддерживаться несколько тем, обязательные: "тёмная" и "светлая", дополнительная: "светлая контрастная".

1. Системные цвета мелких деталей (иконки, границы, индикаторы), одинаковые для тёмной и светлой темы:
-   **hover** (фокус / наведение мыши): `#C6D3E4` — **rgb(198, 211, 228)**
-   **enabled** (активное состояние по умолчанию): `#A5B1C0` — **rgb(165, 177, 192)**
-   **disabled** (заблокированное состояние): `#88919C` — **rgb(136, 145, 156)**
-   **work** (процесс / информационный / ок): `#409EFD` — **rgb(64, 158, 253)**
-   **work_disabled** (процесс / информационный / ок): `#409EFD` — **rgb(37, 90, 143)**
-   **bad** (критическая ошибка / опасность): `#E15604` — **rgb(225, 86, 4)**
-   **wrn** (предупреждение / внимание): `#FFC600` — **rgb(255, 198, 0)**
2. Светлая тема (Light Theme)
-   **bg** (основной фон окон): `#F3F5F8` — **rgb(243, 245, 248)**
-   **bg_accent** (панели, карточки, выделения): `#E2E6EB` — **rgb(226, 230, 235)**
-   **text** (основной текст — глубокий тёмно-серый): `#1A2129` — **rgb(26, 33, 41)**
-   **text_muted** (подписи, второстепенный текст): `#627285` — **rgb(98, 114, 133)**
-   **link** (гиперссылки — контрастный синий): `#0066CC` — **rgb(0, 102, 204)**
3. Тёмная тема (Dark Theme)
-   **bg** (основной фон окон): `#1B2125` — **rgb(27, 33, 37)**
-   **bg_accent** (панели, карточки, выделения): `#263036` — **rgb(38, 48, 54)**
-   **text** (основной текст — мягкий белый): `#E8ECEF` — **rgb(232, 236, 239)**
-   **text_muted** (подписи, второстепенный текст): `#8EA1B4` — **rgb(142, 161, 180)**
-   **link** (гиперссылки — яркий лазурный): `#58B2FF` — **rgb(88, 178, 255)**

Для удобного переключения тем на лету лучше всего использовать динамический класс-контейнер. Компоненты приложения (включая наши самодельные иконки) будут подписываться на событие смены темы и автоматически обновлять свои цвета.

Пример оформления цветов интерфейса:
```python
class ThemeManager(QObject):
    theme_changed = Signal()

    def __init__(self):
        super().__init__()
        self.detail_hover = QColor("#C6D3E4")
        self.detail_enabled = QColor("#A5B1C0")
        self.detail_disabled = QColor("#88919C")
        self.detail_work = QColor("#409EFD")
        self.detail_bad = QColor("#E15604")
        self.detail_wrn = QColor("#FFC600")

        self.bg = QColor()
        self.bg_accent = QColor()
        self.text = QColor()
        self.text_muted = QColor()
        self.link = QColor()

        self.set_dark_theme()

    def set_dark_theme(self):
        self.bg.setNamedColor("#1B2125")
        self.bg_accent.setNamedColor("#263036")
        self.text.setNamedColor("#E8ECEF")
        self.text_muted.setNamedColor("#8EA1B4")
        self.link.setNamedColor("#58B2FF")
        self.theme_changed.emit()

    def set_light_theme(self):
        self.bg.setNamedColor("#F3F5F8")
        self.bg_accent.setNamedColor("#E2E6EB")
        self.text.setNamedColor("#1A2129")
        self.text_muted.setNamedColor("#627285")
        self.link.setNamedColor("#0066CC")
        self.theme_changed.emit()
```
