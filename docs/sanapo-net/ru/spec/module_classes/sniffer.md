## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`, реализующий захват сетевых кадров.
Является ключевым элементом слоя сканеров, работает в выделенном потоке `[[scanner_sniffer.thread]]` с высоким приоритетом, чтобы исключить пропуски пакетов на загруженных сетевых интерфейсах.
Для работы использует сырые сокеты Python (`socket.socket(socket.AF_PACKET, socket.SOCK_RAW)`) или библиотеку Scapy.
