## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. Для проведения сложных математических расчетов (регрессионный анализ, корреляции) и отрисовки тяжелых аналитических дашбордов интегрирует специализированные сторонние Python-библиотеки. 

Информацию для работы приложение запрашивает через менеджер [[db_analytic.unit]] из базы данных [[analytic.database]], где юнит [[analytic.unit]] уже хранит готовые схлопнутые профили за недели, месяцы и годы. Это защищает систему от фризов, так как приложению не приходится самостоятельно высчитывать тренды по миллиардам сырых записей из [[icmp_raw.database]].
