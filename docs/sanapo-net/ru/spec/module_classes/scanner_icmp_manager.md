## Общее тех-задание


Содержит управляющий модуль (объект) `=link(this.module_class)`, внутри которого инкапсулирован объект самого сканера [[ScannerIcmp.class]].
Менеджер взаимодействует с другими юнитами и содержит цикл, генерирующий события наступления новых периодов (0.5 / 1 / 2 / 4 / 8 / 24 / 120 секунд). На основе этих событий юнит [[buffer_icmp.unit]] выполняет свои задачи (например, подготовку пула адресов) перед получением результатов сканирования. После завершения опроса сканер отправляет метрики сканирования и результаты в буфер через сообщение-событие фреймворка [[sanapo.fw]]. При этом логика работы с историческими или объемными метриками оптимизирована для записи в локальное хранилище.
