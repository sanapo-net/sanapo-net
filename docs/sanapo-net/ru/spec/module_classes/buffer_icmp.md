## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`.
Ядром юнита является матрица NumPy с кольцевой структурой (circular buffer) на 1200 строк (60 сек * 10 мин * 2 периода в сек) для быстрой перезаписи "in-memory". Количество столбцов динамически соответствует числу устройств в сети плюс заложенный запас пустых столбцов для новых хостов. Такая структура минимизирует накладные расходы перед сбросом данных в историю, что критично приложении с интенсивной записью.
