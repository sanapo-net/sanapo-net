## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`.
Запускает регулярные тяжелые вычислительные задачи (расчет медиан, трендов и доверительных интервалов), агрегируя исторические данные. Чтобы не мешать частой записи сырых метрик в [[icmp_raw.database]], этот юнит считывает данные из архивных баз [[icmp_hours.database]] и [[icmp_days.database]] через менеджер [[db_icmp.unit]]. 

Готовит эталонные аналитические наборы ("схлопнутые" профили):
* **Профиль суток по 10-минуткам:** Собирает данные за последние 30 суток, рассчитывает типичное поведение для каждого 10-минутного интервала внутри дня. Обновляется раз в сутки, используется анализатором каждые 10 минут.
* **Профиль недели по часам:** Собирает данные за последние 30 недель, формирует шаблон типичной недели с детализацией в 1 час. Обновляется раз в неделю, используется каждый час.
* **Профиль недели по суткам:** Собирает данные за последние 30 недель, формирует шаблон недели с детализацией в 1 сутки. Обновляется раз в неделю, используется раз в сутки.
* **Профиль года по суткам:** Собирает данные за последний 1 год, формирует шаблон года с детализацией в 1 сутки (с учетом сезонности). Обновляется раз в месяц, используется раз в сутки.
* **Глобальный тренд деградации:** Анализирует всю доступную историю с шагом в 1 месяц для выявления старения оборудования, забивания каналов и долгосрочного прогнозирования сбоев. Обновляется раз в месяц, строится по запросу пользователя или по расписанию.

Все результаты расчетов юнит сохраняет в отдельную выделенную базу данных [[analytic.database]] через менеджера [[db_analytic.unit]]. При обнаружении глобальных негативных трендов (например, плавный рост задержек из месяца в месяц) юнит публикует сообщения-события в шину для подписчиков: [[smart_dashboard.unit]], [[bot_email.unit]], [[bot_tg.unit]], [[ui.unit]].
