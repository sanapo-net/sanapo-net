## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`, реализующий логику активного TCP-зондирования.
Является активным сервисом, работает в собственном выделенном потоке `[[scanner_tcp.thread]]`, чтобы долгие сетевые таймауты (`Timeout`) не блокировали основной интерфейс программы.
