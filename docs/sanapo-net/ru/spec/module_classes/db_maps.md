## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. Выступает в роли специализированного графического ORM-слоя. Он переводит сложные древовидные и объектные структуры карт класса [[Maps.class]] (включая координаты, типы заливок, толщину линий и связи виджетов) в плоское реляционное представление для SQL-таблиц.

Юнит обеспечивает двустороннюю работу с данными:
* **Прямая выгрузка:** Конвертирует текущее состояние холста из конструктора приложения [[maps.unit.md]] и записывает координаты всех размещенных элементов (стен, столов, хостов, линий связи) в базу данных [[maps.database]].
* **Обратная загрузка:** Считывает строки из таблиц БД, разворачивает их в промежуточные структуры данных, после чего корректно восстанавливает, связывает и инициализирует сложный объект класса [[Maps.class]] для передачи в графический интерфейс.
