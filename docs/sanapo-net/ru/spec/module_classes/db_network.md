## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. 
Выступает в роли прослойки (ORM), преобразуя сложный древовидный объект класса [[Network.class]] (с группами, тегами и свойствами хостов) в плоское представление для реляционных таблиц.

Юнит умеет выполнять выгрузку данных:
* Сохранять текущую структуру сети в основную базу данных [[network.database]].
* Экспортировать данные в текстовый JSON-файл [[network.json]] (для сохранения полной иерархии).
* Экспортировать данные в плоский CSV-файл [[network.csv]] (для удобного редактирования списков устройств в сторонних табличных редакторах).

Юнит умеет выполнять обратную загрузку:
* Читать данные из любого источника (БД, JSON или CSV), разворачивать их в промежуточные таблицы данных, после чего корректно собирать и инициализировать сложный объект класса [[Network.class]].
