## Общее тех-задание


Содержит модуль (объект) `=link(this.module_class)`. Является встраиваемым виджетом рабочего поля суб-окна ([[MdiWindow.class]]) основного интерфейса [[ui.unit]]. Содержит свойство-словарь с кнопками управления (объектами [[MdiButton.class]]) для фильтрации, обновления и экспорта списков.

Для вывода актуальной оперативной информации запрашивает данные в виде сложного словаря из буфера [[buffer_tcp.unit]]. Историю прошлых сканирований и хронологию проверок портов считывает из базы данных через интерфейс [[db_tcp.unit]].
