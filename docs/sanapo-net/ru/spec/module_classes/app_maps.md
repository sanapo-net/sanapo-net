## Общее тех-задание


Один из наиболее сложных и творческих юнитов проекта. Содержит модуль (объект) `=link(this.module_class)`. Является встраиваемым виджетом рабочего поля дочернего суб-окна ([[MdiWindow.class]]) внутри основного интерфейса [[ui.unit]]. Содержит свойство-словарь с кнопками управления (объектами [[MdiButton.class]]) для переключения режимов, масштабирования и работы с элементами конструктора.

Юнит берет эталонный список хостов и их привязки к картам из базы данных [[network.database]] через интерфейс [[db_network.unit]]. Для изменения цвета элементов в реальном времени он напрямую считывает текущие ICMP-метрики устройств из оперативного буфера [[buffer_icmp.unit]] или слушает алерты шины [[sanapo.fw]] от [[analysator.unit.md]].
