## Общее
Класс содержит ряд статических методов, считывающих файлы PNG с различными иконками, нарезающих спрайт и создающих необходимые иконки для кнопок.

Набор пиктограмм — спрайт-лист (атлас текстур), изображение в формате 32-битный RGBA (8 бит на канал) PNG.


## Пиктограммы кнопок
**Набор пиктограмм для кнопок** — набор пиктограмм, где цветовые каналы (RGB) заполнены сплошным белым цветом `#FFFFFF`, а канал прозрачности (Alpha) содержит градиентную маску пиктограммы кнопки с поддержкой полутонов и сглаживания (anti-aliasing), изображающую схематичные упрощённые иконки.

**Пиктограмма кнопки** — отдельное изображение, полученное путём программной нарезки общего *набора пиктограмм для кнопок* один раз при старте приложения.

Хранение иконок: нарезанные маски кэшируются в оперативной памяти (ОЗУ) в виде словаря (`dict`), где ключом выступает имя кнопки, а значением — объект маски.

Цветовые состояния иконок: изменение цвета пиктограмм под различные состояния `MainBtStat` (упоминается в [описании кнопок](./main_bt.md#класс-mainbtbase)) происходит **на лету (в динамике)** средствами графического движка PySide6 без создания промежуточных файлов на диске и без дублирования картинок в ОЗУ.


## Возможный технологический стек реализации в PySide6
1. **Загрузка и нарезка (при старте)**:
   * Класс `PySide6.QtGui.QPixmap` — используется для загрузки всего файла атласа в память.
   * Метод `QPixmap.copy(QRect)` — выполняет высокопроизводительное вырезание прямоугольной области (конкретной иконки) из общего холста по заданным координатам без потери альфа-канала.
2. **Динамическое окрашивание (на лету)**:
   * Класс `PySide6.QtGui.QPainter` — предоставляет инструменты для низкоуровневой отрисовки и композитинга в памяти.
   * Режим смешивания `QPainter.CompositionMode_SourceIn` — ключевая технология. Заменяет исходный белый цвет (`#FFFFFF`) пикселей маски на целевой цвет из палитры, строго сохраняя оригинальные градиентные значения прозрачности (альфа-канала) из исходного PNG.
   * Фильтрация `QPainter.Antialiasing` и `TextAntialiasing` — обеспечивает аппаратное сглаживание краёв при добавлении динамических элементов (например, кружков уведомлений и цифр) поверх иконки.
