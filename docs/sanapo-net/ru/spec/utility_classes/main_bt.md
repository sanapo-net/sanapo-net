## Класс BaseMainButton
Базовый класс кнопки боковой панели главного окна приложения.
Занимает пространство на экране 48x48 пикселей.
В центре иммет пиктограмму кнопки размером 32x32 или 24x24 пикселей (не определено!)

Кнопка иммет флаг досупности `self.enabled: bool`
Кнопка иммет статус `self.status: MainBtStat` (`class MainBtStat`)

Если кнопка недосупна то ее статус не статус не меняется при наведении курсора мыши и при клике ничего не происходит.

Кнопка может быть в разных состояниях `MainBtStat` и ее пиктограмма принимает соответствующий цвет из списка цветов. Имена всетов описаны в [разделе Темы документа описывающего Юнит "UI"](../module_classes/ui.md#темы)

```python
# /core/enums.py
class MainBtStat(Enum, str):
    HOVER = "hover"
    ENABLED = "enabled"
    DISABLED = "disabled"
    WORK = "work"
    BAD = "bad"
    WRN = "wrn"
```

## Класс MainButtonSwitch
Кнопка - переключатель.

- Доступна:
    - Курсор наведен: оформление: hover/bg
    - Курсор не наведен: оформление: enable/bg
    - Клик: переключает оформление между work/bg и enable/bg и вызывает записанные в `self.turn_on` и `self.turn_off` коллбэки методы с параметром `self.param`
- Недоступна:
    - Курсор наведен: не меняет оформление, нет поведения
    - Курсор не навден: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg или work_disabled/bg

## Класс MainBtMenu
Кнопка - меню.

- Доступна:
    - Курсор наведен: оформление: hover/bg
    - Курсор не наведен: оформление: enable/bg
    - Клик нечетный: оформление */bg_accent и открывает суб-панель кнопок (горизонтальная панель, высотой 48 пикселей, в ширину 48x[количество кнопок])
    - Клик четный: оформление */bg и закрывает суб-панель кнопок (если открыта)
    - При клике на любую кнопку в суб-панели кнопок: оформление */bg и закрывает суб-панель кнопок (если открыта)
- Недоступна:
    - Курсор наведен: не меняет оформление, нет поведения
    - Курсор не навден: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg и закрывает суб-панель кнопок (если открыта)

## Класс MainBtApp
Кнопка - меню.

- Доступна (приложение не работает):
    - Курсор наведен: оформление: hover/bg
    - Курсор не наведен: оформление: enable/bg
    - Клик: оформление work/bg_accent, открывает окно и запускает суб-приложение
- Доступна (приложение работает):
    - Курсор наведен: оформление: hover/bg
    - Курсор не наведен: оформление: work/bg
    - Клик после запуска нечетный: оформление work/bg, сворачивает окно (окно не отображается)
    - Клик после запуска четный: оформление work/bg_accent, разворачивает окно (окно отображается)
- Недоступна:
    - Курсор наведен: не меняет оформление, нет поведения
    - Курсор не навден: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg или work_disabled/bg
