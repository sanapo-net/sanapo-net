## Класс MainBtBase
Базовый класс кнопки боковой панели главного окна приложения.
Занимает пространство на экране 48x48 пикселей.
В центре имеет пиктограмму кнопки размером 32x32 или 24x24 пикселей (не определено!)

Кнопка имеет флаг доступности `self.enabled: bool`
Кнопка имеет статус `self.status: MainBtStat` (`class MainBtStat`)

Если кнопка недоступна, то её статус не меняется при наведении курсора мыши, и при клике ничего не происходит.

Кнопка может быть в разных состояниях `MainBtStat`, и её [пиктограмма](./icons.md) принимает соответствующий цвет из списка цветов. Имена цветов описаны в [разделе "Темы" документа, описывающего юнит "UI"](../module_classes/ui.md#темы)

```python
# /core/enums.py
class MainBtStat(Enum, str):
    HOVER = "hover"
    ENABLED = "enabled"
    DISABLED = "disabled"
    WORK = "work"
    BAD = "bad"
    WRN = "wrn"
```

## Класс MainBtSwitch
Кнопка-переключатель.

- Доступна:
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: enable/bg
    - Клик: переключает оформление между work/bg и enable/bg и вызывает записанные в `self.turn_on` и `self.turn_off` колбэк-методы с параметром `self.param`
- Недоступна:
    - Курсор наведён: не меняет оформление, нет поведения
    - Курсор не наведён: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg или work_disabled/bg

## Класс MainBtMenu
Кнопка-меню.

- Доступна:
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: enable/bg
    - Клик нечётный: оформление */bg_accent и открывает суб-панель кнопок (горизонтальная панель высотой 48 пикселей, шириной 48 × [количество кнопок])
    - Клик чётный: оформление */bg и закрывает суб-панель кнопок (если открыта)
    - При клике на любую кнопку в суб-панели: оформление */bg и закрывает суб-панель кнопок (если открыта)
- Недоступна:
    - Курсор наведён: не меняет оформление, нет поведения
    - Курсор не наведён: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg и закрывает суб-панель кнопок (если открыта)

## Класс MainBtApp
Кнопка-приложение.

- Доступна (приложение не работает):
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: enable/bg
    - Клик: оформление work/bg_accent, открывает окно и запускает суб-приложение
- Доступна (приложение работает):
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: work/bg
    - Клик после запуска нечётный: оформление work/bg, сворачивает окно (окно не отображается)
    - Клик после запуска чётный: оформление work/bg_accent, разворачивает окно (окно отображается)
- Недоступна:
    - Курсор наведён: не меняет оформление, нет поведения
    - Курсор не наведён: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg или work_disabled/bg
