## Общее
Окно состоит из:
- полосы с заголовком суб-приложения и тремя кнопками управления окном 🗕, 🗖/🗗, ✖ (высота полосы минималистична, чтобы не занимать полезное пространство экрана, от 16 до 24 пикселей);
- панели кнопок (сверху на всю ширину, высотой 24–32 пикселя);
- поля контента — то, ради чего окно существует: отображать контент суб-приложения.

Панель кнопок наполняется слева направо объектами: кнопками, переключателями, полями ввода текста, ползунками (все в одном стиле).
- все элементы управления имеют всплывающие подсказки, появляющиеся через 200–300 мс;
- переключатель визуально меняет цвет;
- поле ввода текста содержит текст по умолчанию и кнопку сброса введённого текста; текст по умолчанию имеет приглушённый цвет и, как правило, является подсказкой о том, что нужно вводить;
- ползунки передвигаются по дискретным значениям из определённого списка; при перетаскивании ползунка всплывающая подсказка отображает выбранное значение;
- выбор элемента из списка;
- множественный выбор элементов из списка.
