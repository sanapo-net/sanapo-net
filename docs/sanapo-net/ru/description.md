# Краткое описание программы для конечных пользователей

Sanapo-net - это система мониторинга компьютерных сетей. Она автоматически проверяет доступность устройств, собирает данные об их производительности, строит графики, предупреждает о проблемах через Telegram или E-mail, обнаруживает новые устройства в сети, собирает о них информацию и сообщает о их появлении. Вы можете видеть состояние сети в реальном времени, анализировать историю и получать отчёты. Никаких специальных знаний для работы не требуется - всё управление через удобный оконный интерфейс. Позволяет составлять карты и схемы логического и физического/георграфического расположения техники.
