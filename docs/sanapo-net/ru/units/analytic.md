## Описание
Юнит долгосрочного статистического прогнозирования и формирования эталонных метрик для фреймворка [[sanapo.fw]]. На основе глубокого анализа архивных баз данных он создает математические профили нормального поведения сети. Эти эталоны используются анализатором [[analysator.unit.md]] для обнаружения аномалий, а также выводятся пользователю для оценки деградации каналов связи.
