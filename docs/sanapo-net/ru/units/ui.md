## Описание
Главное окно программы, реализующее полноценный MDI-интерфейс (многооконный графический интерфейс, позволяющий пользователю открывать, перемещать и сворачивать несколько дочерних окон суб-приложений внутри одного общего родительского окна). 
Основное окно служит единой рабочей графической средой приложения. Оно визуально разделено на панель кнопок, панель запущенных приложений (панель задач) и центральное рабочее поле, в котором оператор настраивает свое рабочее пространство манипулируя с суб-приложениями и их окнами.
