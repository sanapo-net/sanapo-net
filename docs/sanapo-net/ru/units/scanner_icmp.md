## Описание
Сканирует сеть по протоколу ICMP и отправляет сообщения-события с результатами сканирования в главную шину фреймворка [[sanapo.fw]].
Данные для сканирования получает из юнита сети [[network.unit.md]]. Модуль содержит цикл с таймером, по которому осуществляет периодический опрос устройств в сети.
Поддерживает сканирование разных устройств с разным интервалом. По команде пользователя может ускорять темп (уменьшать интервал) и замедлять темп (увеличивать интервал) сканирования в два раза.
В будущем планируется добавление функционала динамического изменения темпа сканирования для всех, группы или одного конкретного устройства по команде внешнего юнита - например, анализатора [[analysator.unit.md]] (#future).
