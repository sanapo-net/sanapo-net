## Описание
Интерактивное графическое приложение для визуализации сетевой топологии на логических схемах, планах помещений и географических картах. Отображает сетевые устройства и связи между ними, помогая оператору визуально контролировать структуру и физическое расположение инфраструктуры. Поддерживает полноценный режим редактирования (конструктор карт) и несколько динамических режимов просмотра для мониторинга состояния сети.
