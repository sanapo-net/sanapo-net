## Описание
Приложение для визуализации графиков ICMP-сканирования в реальном времени. 
Отображает динамику метрик за последние минуты, помогая оператору визуально оценивать стабильность сети. 
Поддерживает несколько режимов просмотра в зависимости от выбранного масштаба времени и фильтров.
