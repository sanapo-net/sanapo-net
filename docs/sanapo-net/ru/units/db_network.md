## Описание
Интерфейсный юнит для работы со структурой сети во фреймворке [[sanapo.fw]]. 
Отвечает за надежное сохранение, хранение и загрузку полных данных обо всех сетевых устройствах с помощью базы данных [[network.database]]. 
Обеспечивает гибкий экспорт и импорт конфигурации и параметров объектов сети в текстовые форматы JSON и CSV для резервного копирования или быстрой настройки системы.
