## Описание
Фоновый сервисный юнит для автоматической идентификации, профилирования и обогащения данных о сетевых устройствах. Позволяет по любому одиночному известному признаку (IP-адрес, MAC-адрес или сетевое имя) собрать полноценное техническое досье на хост. Сервис работает как в автоматическом режиме по запросам от других сканеров фреймворка [[sanapo.fw]], так и в интерактивном режиме по прямой команде оператора из интерфейса [[ui.unit]].
