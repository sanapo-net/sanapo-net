# Архитектура sanapo-net (кратко)

Программа построена на фреймворке [sanapo](../../sanapo/ru/architecture.md), который обеспечивает работу изолированных, малосвязанных юнитов, обменивающиеся сообщениями через шину. Ключевые архитектурные слои:

**Сканеры** - активные и пассивные источники данных (ICMP, TCP, Sniffer, HostProfiler).
**Буферы** - высоконагруженные in-memory агрегаторы, кэширующие метрики и распределяющие их подписчикам.
**Менеджеры БД** - ORM-прослойки между быстрой логикой и базами данных SQLite.
**Cеть** - виртуальное представление сети, управление слепками.
**Карты** - представление физического и/или логического расположения устройств в сетях
**Аналитика** - вычисление эталонов, обнаружение аномалий.
**Приложения** - графические интерфейсы, дашборды и боты, работающие на данных из шины.
**Графическая оболочка** - MDI-интерфейс, окна, кнопки.

Взаимодействие между слоями происходит только через сообщения, что гарантирует потокобезопасность и лёгкую масштабируемость.
