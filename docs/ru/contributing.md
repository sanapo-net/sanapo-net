# Лицензирование вклада
Отправляя Pull Request, вы соглашаетесь, что ваш код будет распространяться под той же лицензией, что и проект: Business Source License 1.1 до 2030‑01‑01, затем Apache 2.0 License.

# Как внести вклад

    **Форкните репозиторий** и создайте ветку для своей функции или исправления (git checkout -b feature/КласснаяФича).

    **Зафиксируйте изменения** (git commit -m 'Добавлена КласснаяФича').

    **Отправьте ветку** (git push origin feature/КласснаяФича).

    **Откройте Pull Request**.

Можно создать ветку прямо здесь, пишите в личку!

# Направления, требующие помощи

- **Графический интерфейс** – Миграция с Tkinter в MPV на PySide6 в версии 1 (Qt for Python). Нужна помощь в переносе существующих MDI‑окон, карт, графиков и элементов управления.
- **Топологический движок** – Написание отрисовки карт, поддержка уровней L1/L2/L3 и гибридных, визуальное редактирование элементов (стены, стойки, линии связи), переключение между картами.
- **Сканеры** – Добавление сканера TCP/UDP.
- **Базы данных** – Реализация дополнительных бэкендов (PostgreSQL, MySQL) наряду с текущими SQLite‑файлами в WAL‑режиме. Адаптация менеджеров DbIcmp, DbSys и др.
- **Тестирование** – Написание модульных и интеграционных тестов для юнитов (сканеры, буферы, аналитика, менеджеры БД). Помощь в настройке CI.
- **Производительность** – Оптимизациярендеринга графиков (ChartRenderer, CandlestickRenderer).
- **Ядро sanapo** – Улучшение фреймворка sanapo, заготовлен упрощенный список ["TODO in ver2"](./docs/sanapo/en/todo-v2.md)

# Стандарты кода

- Следуйте стилю кодирования проекта.
- Добавляйте понятные комментарии к нетривиальным участкам.
- Перед отправкой PR убедитесь, что все тесты проходят.
- Используйте осмысленные сообщения коммитов.
- Длинна строк до 100 символов.
- Аннотации в обявлениях функций/методов и свойств в `__init__()`.
- Комментации и док стринги на английском языке, максимально простыми словами.
- Желаемые размеры: Модули 200-600 строк, Функции/Методы 5-50 строк, вложенность втури функий/методов до 4 уровня.
- Для сложных типов - использовать алиасы.
