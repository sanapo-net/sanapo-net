## Описание
Является пассивным приложением (сервисом) для непрерывного перехвата и низкоуровневого разбора сетевого трафика.
Не генерирует и не отправляет пакеты в сеть, работая полностью скрытно.
Служит главным источником пассивных метрик: выявляет открытые TCP-сервисы, обнаруживает новые устройства по широковещательным протоколам и мгновенно фиксирует сетевую активность хостов для анализа их онлайн-статуса.
