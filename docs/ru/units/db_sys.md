## Описание
Главный интерфейс для работы с базами данных системных метрик. Отвечает за надежное сохранение, агрегацию, долгосрочное хранение и выдачу показателей производительности (процессор, память, диски, сеть) с хостов, на которых развернуты локальные агенты мониторинга. Юнит полностью управляет набором баз данных: [[sys_raw.database]], [[sys_10m.database]], [[sys_hour.database]] и [[sys_day.database]].
