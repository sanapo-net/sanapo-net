# Юнит: BOT_TG

Модульный класс: [bot_tg](../spec/module_classes/bot_tg.md)
Поток: BOT_TG
Слой: BOTS

## Описание
Находится в одном Слое с Юнитом [BOT_EMAIL](./bot_email.md) аналогичного назначения.

Юнит отвечает за удаленную связь с конечными пользователями через месседжер Telegramm.

Уведомляет пользователя о происходяем в сети разбивая информацию на три группы (HIGH MEDIUM LOW) отправляя ее в три разных чата, за счет которых пользователь сможет насторить автоматическую сортировку сообщений средствами скриптов, а так же настроить тип уведомлений в каждом чате.

Первая строка сообщения имеет так же кратчайшую информацию о событии - пользователь не открывая сообщение сможет понимать примерную суть сообщения бегло прочитав входящие.

Пользователь может отправлять некоторые предусмотренные запросы в систему, на которые система должа ответить с запрошенной информацией.

Бот позволяет системным, сетевым администраторам, администраторам безопасности, руководителям соответствующих подразделений и другим пользователям которым важно знать например информацию об отключении устройств быть в курсе происходящего в сети даже в нерабочее время, а так же позволяет не беспокоить их по не слишком важным событиям в сети.
