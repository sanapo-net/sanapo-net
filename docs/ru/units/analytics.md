## Описание
Полнофункциональное аналитическое приложение для визуализации глубокой статистики и построения прогнозных графиков. Позволяет пользователю через гибкий конструктор выбирать периоды, типы устройств, группы хостов и метрики для поиска скрытых взаимосвязей в сети. 
Проект запланирован к разработке в качестве масштабного расширения платформы сразу после официального релиза базовой версии sanapo-net v1.0.
