## Описание
Является виртуальной копией, отражением реальной вычислительной сети в памяти программы.
Хранит в себе данные обо всех элементах: устройствах, их сетевых интерфейсах (IP/MAC) и соединениях между ними.
Нужен для того, чтобы другие части программы (сканеры, интерфейс) всегда знали актуальный состав сети.
Может выполнять манипуляции с содержимым сети по команде: добавлять, редактировать, удалять элементы.
