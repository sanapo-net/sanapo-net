# Спецификация: Вспомогательные классы для Mdi (SubWindow, Icons, MainBt, MainBtStat, MainBtSwitch, MainBtApp)



# SubWindow
## Данные
файл: /modules/ui/sub_window.py
модули: [ui](../module_classes/ui.md)

## Общее
Окно состоит из:
- полосы с заголовком суб-приложения и тремя кнопками управления окном 🗕, 🗖/🗗, ✖ (высота полосы минималистична, чтобы не занимать полезное пространство экрана, от 16 до 24 пикселей);
- панели кнопок (сверху на всю ширину, высотой 24–32 пикселя);
- поля контента — то, ради чего окно существует: отображать контент суб-приложения.

Панель кнопок наполняется слева направо объектами: кнопками, переключателями, полями ввода текста, ползунками (все в одном стиле).
- все элементы управления имеют всплывающие подсказки, появляющиеся через 200–300 мс;
- переключатель визуально меняет цвет;
- поле ввода текста содержит текст по умолчанию и кнопку сброса введённого текста; текст по умолчанию имеет приглушённый цвет и, как правило, является подсказкой о том, что нужно вводить;
- ползунки передвигаются по дискретным значениям из определённого списка; при перетаскивании ползунка всплывающая подсказка отображает выбранное значение;
- выбор элемента из списка;
- множественный выбор элементов из списка.



# Icons
## Данные
файл: /modules/ui/icons.py
модули: [ui](../module_classes/ui.md)

## Общее
Класс содержит ряд статических методов, считывающих файлы PNG с различными иконками, нарезающих спрайт и создающих необходимые иконки для кнопок.
Набор пиктограмм — спрайт-лист (атлас текстур), изображение в формате 32-битный RGBA (8 бит на канал) PNG.

## Пиктограммы кнопок
**Набор пиктограмм для кнопок** — набор пиктограмм, где цветовые каналы (RGB) заполнены сплошным белым цветом `#FFFFFF`, а канал прозрачности (Alpha) содержит градиентную маску пиктограммы кнопки с поддержкой полутонов и сглаживания (anti-aliasing), изображающую схематичные упрощённые иконки.

**Пиктограмма кнопки** — отдельное изображение, полученное путём программной нарезки общего *набора пиктограмм для кнопок* один раз при старте приложения.

Хранение иконок: нарезанные маски кэшируются в оперативной памяти (ОЗУ) в виде словаря (`dict`), где ключом выступает имя кнопки, а значением — объект маски.

Цветовые состояния иконок: изменение цвета пиктограмм под различные состояния `MainBtStat` (упоминается в [описании кнопок](#mainbt)) происходит **на лету (в динамике)** средствами графического движка PySide6 без создания промежуточных файлов на диске и без дублирования картинок в ОЗУ.

## Возможный технологический стек реализации в PySide6
1. **Загрузка и нарезка (при старте)**:
   * Класс `PySide6.QtGui.QPixmap` — используется для загрузки всего файла атласа в память.
   * Метод `QPixmap.copy(QRect)` — выполняет высокопроизводительное вырезание прямоугольной области (конкретной иконки) из общего холста по заданным координатам без потери альфа-канала.
2. **Динамическое окрашивание (на лету)**:
   * Класс `PySide6.QtGui.QPainter` — предоставляет инструменты для низкоуровневой отрисовки и композитинга в памяти.
   * Режим смешивания `QPainter.CompositionMode_SourceIn` — ключевая технология. Заменяет исходный белый цвет (`#FFFFFF`) пикселей маски на целевой цвет из палитры, строго сохраняя оригинальные градиентные значения прозрачности (альфа-канала) из исходного PNG.
   * Фильтрация `QPainter.Antialiasing` и `TextAntialiasing` — обеспечивает аппаратное сглаживание краёв при добавлении динамических элементов (например, кружков уведомлений и цифр) поверх иконки.

# MainBt

## Данные
файл: /modules/ui/main_bt.py
модули: [ui](../module_classes/ui.md)

## Общее
Базовый класс кнопки боковой панели главного окна приложения.
Занимает пространство на экране 48x48 пикселей.
В центре имеет пиктограмму кнопки размером 32x32 или 24x24 пикселей (не определено!)

Кнопка имеет флаг доступности `self.enabled: bool`
Кнопка имеет статус `self.status: MainBtStat` (`class MainBtStat`)

Если кнопка недоступна, то её статус не меняется при наведении курсора мыши, и при клике ничего не происходит.

Кнопка может быть в разных состояниях `MainBtStat`, и её [пиктограмма](#icons) принимает соответствующий цвет из списка цветов. Имена цветов описаны в [разделе "Темы" документа, описывающего юнит "UI"](../module_classes/ui.md#темы)



# MainBtSwitch
## Данные
файл: /modules/ui/main_bt.py
модули: [ui](../module_classes/ui.md)

## Общее
Кнопка-переключатель.
- Доступна:
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: enable/bg
    - Клик: переключает оформление между work/bg и enable/bg и вызывает записанные в `self.turn_on` и `self.turn_off` колбэк-методы с параметром `self.param`
- Недоступна:
    - Курсор наведён: не меняет оформление, нет поведения
    - Курсор не наведён: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg или work_disabled/bg



# MainBtMenu
## Данные
файл: /modules/ui/main_bt.py
модули: [ui](../module_classes/ui.md)

## Общее
Кнопка-меню.
- Доступна:
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: enable/bg
    - Клик нечётный: оформление */bg_accent и открывает суб-панель кнопок (горизонтальная панель высотой 48 пикселей, шириной 48 × [количество кнопок])
    - Клик чётный: оформление */bg и закрывает суб-панель кнопок (если открыта)
    - При клике на любую кнопку в суб-панели: оформление */bg и закрывает суб-панель кнопок (если открыта)
- Недоступна:
    - Курсор наведён: не меняет оформление, нет поведения
    - Курсор не наведён: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg и закрывает суб-панель кнопок (если открыта)



# MainBtApp
## Данные
файл: /modules/ui/main_bt.py
модули: [ui](../module_classes/ui.md)

## Общее
Кнопка-приложение.
- Доступна (приложение не работает):
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: enable/bg
    - Клик: оформление work/bg_accent, открывает окно и запускает суб-приложение
- Доступна (приложение работает):
    - Курсор наведён: оформление: hover/bg
    - Курсор не наведён: оформление: work/bg
    - Клик после запуска нечётный: оформление work/bg, сворачивает окно (окно не отображается)
    - Клик после запуска чётный: оформление work/bg_accent, разворачивает окно (окно отображается)
- Недоступна:
    - Курсор наведён: не меняет оформление, нет поведения
    - Курсор не наведён: не меняет оформление, нет поведения
    - Клик: не меняет оформление, нет поведения
    - При становлении недоступной: оформление: disable/bg или work_disabled/bg
