# Brief Description of the Program for End Users
[Русская версия](../ru/description.md)

Sanapo-net is a computer network monitoring system. It automatically checks device availability, collects performance data, builds graphs, alerts you about issues via Telegram or email, detects new devices on the network, gathers information about them, and notifies you of their appearance. You can view the network status in real time, analyze historical data, and receive reports. No special expertise is required – all management is done through a convenient graphical interface. It also allows you to create maps and diagrams of the logical and physical/geographical layout of your equipment.
